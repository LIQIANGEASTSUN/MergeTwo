# 方法与筛选过程

1. 输入为原 XAPK 中的 Unity IL2CPP `libil2cpp.so` 和 metadata。AssetRipper 导出 C# 结构稿；Il2CppDumper 恢复类型签名与原生 RVA；Ghidra 按导入映像基址 `0x10000` 对应 `native_entry = RVA + 0x10000` 导出伪 C。
2. 从原候选目录 763 份脚本中，按 `MergeBoard` 覆写、二合规则/交互/生成/消耗/锁定/存档方法、原生直接调用和类型引用筛选。保留完整脚本，不重写或拼接方法。筛选逐项见[筛选清单](筛选清单.csv)。
3. 纯媒体资产原目录本来就没有。本次进一步排除遥测协议、纯展示界面、活动商城/奖励结构和无独特实现的重复棋盘格载体。与二合机制确实有关的活动棋盘变体保留。
4. 伪 C 的地址校正、尾调用覆盖与延时重试见[完整性说明](完整性说明.md)。所有结果均是静态工具输出，未伪造缺失方法体。

5. 再次审查后移除了 11 份纯活动展示或通用框架脚本及对应原生输出；完整保留相关活动的产出/评分模型。

6. 再移除一份仅负责背包条目视觉状态的脚本及其伪 C；背包取用方法保留。

7. 删除装修解锁气泡和两份无保留代码引用的独立表结构，保留实际由 MergeManager 调用的 CreatorMergeLineFix。
