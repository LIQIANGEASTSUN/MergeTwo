# 逆向完整性说明

- 保留 **342 份完整 C# 结构稿**、**840 个原样 Il2CppDumper 类型块**和 **10788 条方法记录**，范围及删除理由见[筛选清单](筛选清单.csv)。这是对上一版 763 份候选脚本的逐轮筛选，不代表安装包只有这些类型。
- 保留的原生方法状态：`decompiled_rebased_without_autoanalysis` 10491、`pseudocode_partial_bad_instruction` 227、`no_native_rva` 34、`decompiled_tailcall_override` 35、`pseudocode_retry_with_warnings` 1。逐条见[方法索引](managed_method_index.csv)。
- `decompiled_rebased_without_autoanalysis`：从实际 ARM 机器码生成了非空伪 C，但未经过完整全库自动分析；不保证类型、函数边界或行为完整。
- `decompiled_tailcall_override`：逐条核验 ARM 的 `b` 和目标后，在 Ghidra 设置 `CALL_RETURN` 控制流覆盖并重导；见[尾调用修正说明](尾调用修正说明.md)。
- `pseudocode_partial_bad_instruction`：伪 C 含 `halt_baddata`，控制流截断。`pseudocode_retry_with_warnings`：长时重试得到伪 C，但含多处 Ghidra 控制流警告。`decompile_failed`：未得到伪 C，仅在有保留的 ARM 区间时能读汇编。`no_native_rva`：仅有签名/结构。
- AssetRipper `.cs` 中的空方法体和 `return 0/false/null` 是工具占位，**不是原作者的 C# 方法实现**。`.c` 是工具生成的原生伪代码，也不是原始 C#。IL2CPP 已丢失原局部变量名、注释与源文件布局。
- 保留了用于核验尾调用及失败方法的 ARM 汇编区间；区间可能含字面量池或因 64 KiB 上限截断。未运行游戏进行动态验证。
