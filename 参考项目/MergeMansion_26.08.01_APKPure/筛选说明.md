# 二合代码筛选说明

本次从原先交付的 1,665 个脚本中按完整文件保留 836 个，移除 829 个。未修改保留脚本或原生代码文件的任何字节；`代码索引.json` 记录每个保留脚本的原 SHA-256，`SHA256SUMS.txt` 记录最终文件哈希。

逐个检查原目录文件类型后，未发现逆向导出的图片、音频、模型、动画、Unity 配置或二进制资源。删除了两份 Finder 自动产生的 `.DS_Store`。最终目录仅包含逆向代码（C#、ARM64/ISIL、伪 C）及检索、方法、可信度和安装包来源说明文件。

筛选时保留棋盘、坐标与摆放、物品、二合判定及结果、生成与消耗、泡泡、箱子、锁定与解锁、能量、库存与口袋、玩家动作、状态与迁移、合成任务、相关活动棋盘和直接依赖。对引用链上的基础类、接口、枚举和少量活动类型，即使名称看似非二合，也予以保留。纯视觉交互代码只保留直接承担棋盘操作或物品信息交互的脚本。

删除的代码主要是自动化机器人与测试、开发作弊动作、商城/IAP/社交/邮件、排行榜运营逻辑、卡牌收集与每日任务系统、非棋盘活动奖励、纯展示界面、音效/VFX 类型、分群属性和统计 DTO。部分被保留的完整脚本本身仍含其他系统字段或方法，这是原始类的组成部分，未在脚本内部删改。筛选结果不构成可独立编译的 Unity 项目；仍可能引用未保留的商业化或活动类型。

`代码索引.json`、`类型索引.csv`、`脚本签名索引.csv`、`方法索引.csv` 和调用索引均与筛选结果同步。Ghidra 伪 C 仅保留对应已保留方法的文件，且需结合 `伪C质量初筛.csv` 判断工具输出局限。这里的 C# 空方法是工具占位，伪 C 和 ISIL 是原生代码逆向输出，`核心流程可读伪代码.md` 是人工释读。
