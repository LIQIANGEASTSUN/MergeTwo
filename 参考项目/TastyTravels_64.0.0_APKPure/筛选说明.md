# 筛选与依赖追踪

本次从原先 1173 份脚本中保留 563 份，移除 610 份。筛选依据是 AssetRipper 导出的类型/继承/接口声明、C# 字段和签名引用，以及 Il2CppDumper 地址与 ARM 直接调用的对应关系。逐文件理由见 `script_index.csv` 和 `prune_manifest.json`。

保留范围：`FAT.Merge` 的全部核心类；主棋盘的输入、物品状态、生成、消耗、库存、订单及存档边界；直接操纵棋盘物品的活动棋盘扩展；相应的存档结构、配置数据类型、基类、接口和消息类型。活动代码只有涉及二合棋盘和物品实际操作时才保留。普通活动进度、竞赛、商店、广告、音频、纯装饰 UI 和大量其他配置访问数据未保留。

`fat.conf.Data.cs` 是例外：`ItemUtility.IsDropLimitItem` 直接调用其中的 `GetDropLimitScore`。原要求规定相关脚本必须整份保留，所以它的其他配置访问器仍在同一文件中；不能把它们误认为二合逻辑。汇总方法索引与 ARM 文件只收录该脚本已反编译的方法及本目录调用路径上的访问器，省略了 7925 个无关或未尝试的原生方法段；完整签名仍在未改动的 `Data.cs` 中。

每份入选的 C# 和伪 C 文件均整文件原样复制，不裁剪方法。汇总反汇编与 CSV 仅保留入选脚本对应的方法/调用边，并重算反汇编行号。被移除的外围类型可能仍以方法名或字段类型出现在代码中；本目录是阅读参考，并不承诺可独立编译。静态调用表也不覆盖虚调用、委托、反射与热修复。
