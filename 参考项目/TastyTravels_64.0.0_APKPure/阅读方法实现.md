# 阅读方法实现

以 `Board.CanMerge` 为例：

1. 在 [Board.cs](scripts/asmdef_fat_runtime/FAT/Merge/Board.cs) 看类型、字段和签名。空方法体是 AssetRipper 对 IL2CPP 应用生成的占位，不能当作游戏逻辑。
2. 在 `native_method_index.csv` 查 `type=FAT.Merge.Board`、`method=CanMerge`，取得 RVA 和原生签名。
3. 根据同一行的 `pseudoc_file`、`pseudoc_line` 阅读 Ghidra 伪 C；根据 `asm_line` 对照 `native_disassembly.s` 的 ARM 指令。
4. 用 `native_direct_calls.csv` 的 `caller_rva` 追踪静态调用。伪 C 的 `FUN_XXXXXXXX` 使用 Ghidra 映像基址 `0x10000`，对应 Il2CppDumper RVA 为 `XXXXXXXX - 0x10000`。

`native_disassembly.s` 只含本次保留方法的完整指令段；每段仍采用原始相邻注册地址确定的边界。伪 C 是 Ghidra 对机器码的推导，局部变量类型、控制流与调用目标可能不准确；疑点应回看 ARM 指令。原始 `il2cpp_selected_types.dump.cs` 是重复的占位声明汇总，精简时移除；字段和签名请查完整 C# 脚本。
