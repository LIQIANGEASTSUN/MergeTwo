# 逆向方法与完整性

## 输入与技术形式

输入是 `Tasty+Travels_+Merge+Game_64.0.0_APKPure.xapk`，SHA-256 为 `509679b10debe7651f504276feeb38d40b61512b0a06b7886bbaf1d4846edb13`。XAPK 含主 APK、UnityDataAssetPack 和 `config.armeabi_v7a.apk`。游戏是 Unity IL2CPP；代码二进制为 ELF32 ARM `libil2cpp.so`，metadata 文件头为 `0xFAB11BAF`，Il2CppDumper 报告 metadata version 31。

包内 `assets/lua/gen/*.bytes` 中能看到 `$CGF$10` 头的加密配置。后续已从原生解密路径核验部分二合配置结构与少量示例，详见 `二合机制实现推断.md`；本目录仍不保留任何配置资源或完整配置表。运行时热修复、服务端逻辑或动态下载代码的覆盖范围仍无法从本安装包确认。

## 实际执行与工具结果

1. 检查工作仓库 `app_auto_unpack` 的 XAPK 合并、Unity 检测、AssetRipper、Il2CppDumper 和 Ghidra 工具。拆包与逆向项目均放在 `/private/tmp`，原始 XAPK、工作仓库和工具未修改。
2. 首次 AssetRipper 阶段因沙箱阻止本机 socket 报 `PermissionError: [Errno 1] Operation not permitted`。允许本机回环端口后再次执行；第一次导出连接曾报 `ConnectionResetError: [Errno 54] Connection reset by peer`，包装器的第二次尝试完整导出。最终成功。AssetRipper 版本 `1.3.14+7534ed9`。
3. Il2CppDumper 在临时隔离副本中将 `RequireAnyKey` 设为 `false`，获得类型、字段、签名、地址索引、DummyDll。工具输出 `ERROR: This file may be protected.` 警告，但 `dump.cs`、`script.json`、`il2cpp.h` 和 DummyDll 均生成，流程最终校验成功。原工具配置未修改。
4. Ghidra 12.1.2 使用 Android Studio 的 JDK 21，用户目录重定向到临时目录，对选中方法手动反汇编、创建函数后以 `-noanalysis` 导出伪 C。最初未定位 Java Runtime 和默认 Ghidra 用户目录不可写的问题均已解决。Apple LLVM `objdump` 另输出 ARM32 指令。

## 覆盖量

AssetRipper 共导出 9,253 个 C# 脚本。第一轮整理保留 1,173 个，本轮收窄至 563 个完整文件，去掉了 610 个活动、商店、纯表现或间接业务依赖文件。入选原生方法 10346 个、唯一 RVA 10346 个，均保留完整 ARM 指令段；Ghidra 伪 C 状态：10344 个成功、2 个失败、0 个未尝试。RVA 为 -1 的签名 226 条。失败方法为 `FAT.ReasonString..cctor` 与 `FAT.GuideRequireChecker._CheckRequire`，仍有 ARM 指令。详情逐方法见 `native_method_index.csv`；逐文件筛选依据见 `script_index.csv`。

`fat.conf.Data` 是一份自动生成的全局配置访问器：只因二合方法直接调用其 `GetDropLimitScore` 而整份保留。其大量其他访问器与二合无关，因“相关脚本整份保留”原则未在文件内裁剪。原汇总类型转储、外围方法的反汇编/伪 C、运行日志和下载说明已移除。

## 真实性界限

**`scripts/` 中的空方法、`return 0`、`return false` 和 `return null` 是工具生成的占位内容，不是原始游戏逻辑。** 这些文件提供类型结构、继承、字段和签名线索。真正从安装包获得的实现证据是原生 ARM 指令；`pseudo_c/` 是 Ghidra 对指令的推导表达，不是原始 C#。类名、命名空间、字段和签名来自 IL2CPP metadata，也可能受到编译、泛型共享、剥离和热修复影响。

筛选后的 `native_disassembly.s` 用原始相邻注册地址界定方法段，可能包含填充或遗漏未注册地址。Ghidra 未做全量自动分析，局部变量类型、调用符号、分支及异常处理可能不准确；工具日志中也有部分 pcode 警告。`native_direct_calls.csv` 仅记录可静态识别的直接分支，不能覆盖虚调用、委托、反射或其他间接调用。本目录是可追溯的代码参考，不声称已经还原原始 C# 源文件或全部运行时逻辑。
