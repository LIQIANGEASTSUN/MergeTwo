# 逆向完整性

| 层级 | 数量 | 可读到什么 |
|---|---:|---|
| 原始 C# 方法体 | 0 | 安装包采用 IL2CPP，没有可直接恢复的托管 IL。 |
| AssetRipper C# 脚本 | 218 | 类、接口、字段、方法结构；方法体多为工具占位，不能当作游戏逻辑。 |
| Il2CppDumper 类型块 | 671 | 继承、接口、字段偏移、方法签名与 RVA；无真实方法体。 |
| 索引方法 | 3642 | 含属性访问器、构造器、编译器生成方法。 |
| Ghidra 原生伪代码 | 581 | 从 ARM32 机器码推导的 C 风格控制流，不是原始 C#。 |
| 因本轮范围收紧而省略的原生伪代码 | 99 | 已从安装包获得，但属于可辨认的界面、统计、提示或任务评分辅助方法。 |
| 未选入原生反编译的方法 | 2962 | 在本参考目录只有签名或工具占位。 |

Ghidra 导入 ELF 的 image base 为 `0x10000`；实际反编译地址等于 Il2CppDumper RVA 加 `0x10000`。伪代码标题中的 `VA` 是生成脚本使用的 RVA 标签。未进行完整类型还原，参数、局部变量名、类型以及部分函数边界可能不准确。生成成功不等于语义已全部验证。

一个 C# 文件只要含需要保留的二合逻辑，就整文件保存，未删改其中其他成员。因此保留脚本中的个别辅助方法不必然属于二合规则。Il2CppDumper 类型块与 Ghidra 单个函数块也未改写。
