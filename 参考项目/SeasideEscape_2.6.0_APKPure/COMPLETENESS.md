# 逆向完整性与限制

| 层级 | 此次精简结果 | 解释 |
|---|---:|---|
| 主 Lua 容器历史提取 | 1,988 个模块；其中 1,986 个成功反编译 | 从安装包实际解出字节码，不是开发者源码。2 个失败模块不在二合保留范围。 |
| 当前保留 | 178 份完整 `.luac` + 178 份完整 `.lua` | 覆盖主棋盘和有二合规则的活动棋盘、物品组件、订单、库存及必要依赖；入选脚本没有删方法。 |
| 具名函数索引 | 4,622 个 | 函数体由 unluac 从字节码重建，可读控制流；匿名闭包仍在文件中。 |
| 顶层表/动态字段索引 | 304 个表/原型候选；2,155 次字段赋值观测 | Lua 表和动态字段不能当成 C# 正式类或静态字段声明。 |
| 原始开发者 Lua 源码 | 0 | 注释、原排版、部分局部变量名与写法无法可靠恢复。 |
| 原始 C# 托管或 IL2CPP 原生方法体 | 0 | APK 为 IL2CPP；先前工具导出的 C# 空方法是占位，已从精简目录删除。 |

`CanItemMerge`、`DragItem`、`_MergeItem`、`ItemSpread:_TrySpread` 等函数体确实由保留的原字节码反编译得到。每个 `.lua` 都有同路径 `.luac` 对照；[SHA256SUMS.tsv](SHA256SUMS.tsv) 保存文件校验值。178 份反编译 Lua 均通过 Lua 5.3 语法解析；语法通过不等于与运行行为逐指令等价。

静态调用索引只保留双方都在此目录的可唯一匹配调用。Lua 的 `self` 调用、回调、事件、动态加载和运行时覆盖需读原脚本追踪。配置实际数值、可能的远端 Lua 更新与 IL2CPP 原生实现未恢复；不能据 C# 占位或人工推断填补实现。

精简删除了与二合无关的脚本和所有 C# 占位结构，故本目录是**阅读范围**，不是能独立启动的完整游戏工程。原始提取过程、取舍和历史数量分别见 [逆向过程](PROVENANCE.md) 与 [精简依据](PRUNING.md)。
