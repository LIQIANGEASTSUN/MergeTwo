# Seaside Escape 2.6.0 二合代码参考

本目录只保留此版本安装包中与二合玩法直接相关、或理解其流程所必需的代码及少量索引说明。范围包括主棋盘、物品组件、合成与生成、订单、库存和存档，以及会改写二合规则的活动棋盘。所有入选 Lua 脚本均保留完整文件，不裁剪方法。

- [代码索引](CODE_INDEX.md)：按玩法流程定位文件、方法和全量索引。
- [玩法实现分析](MERGE_BEHAVIOR_ANALYSIS.md)：已见代码、跨函数归纳和待验证内容。
- [精简依据](PRUNING.md)：保留与删除的范围、数量和校验方式。
- [完整性与限制](COMPLETENESS.md)：字节码、反编译文本及未恢复内容的区别。
- [逆向过程与溯源](PROVENANCE.md)：安装包、工具、提取步骤和校验。

`code/Lua/bytecode/` 保留 178 个从安装包解出的原 Lua 5.3 模块字节码；`code/Lua/decompiled/` 保留与之一一对应的 178 个完整反编译文本。`.luac` 是代码字节码，不是图片、音频或模型资源。反编译文本可用于阅读函数体，但不是开发者原始 Lua 源码。
